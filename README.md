# ML-project-1-eda-titanic

## Описание данных (Titanic)

| Столбец | Описание | Тип | Особенности |
| :--- | :--- | :--- | :--- |
| **PassengerId** | Уникальный идентификатор пассажира | Целое число | Просто индекс, не влияет на выживание |
| **Survived** | Целевая переменная: 1 – выжил, 0 – погиб | Целое число (0/1) | Класс несбалансирован: 38% выживших |
| **Pclass** | Класс билета (1 – первый, 2 – второй, 3 – третий) | Целое число (1,2,3) | Социально-экономический статус |
| **Name** | Полное имя пассажира | Строка | Можно извлечь титул (мистер, миссис и т.д.) |
| **Sex** | Пол: male / female | Строка | Очень сильный признак |
| **Age** | Возраст в годах | Дробное число | ~20% пропусков; есть младенцы (0.42 года) |
| **SibSp** | Количество братьев/сестёр или супругов на борту | Целое число | Семейное положение |
| **Parch** | Количество родителей или детей на борту | Целое число | Семейное положение |
| **Ticket** | Номер билета | Строка | Много уникальных значений, обычно удаляют |
| **Fare** | Стоимость билета (в фунтах стерлингов) | Дробное число | Сильный перекос – есть выбросы (до 512) |
| **Cabin** | Номер каюты | Строка | 77% пропусков – используют как флаг «есть/нет» |
| **Embarked** | Порт посадки (C = Шербур, Q = Квинстаун, S = Саутгемптон) | Строка | 2 пропуска, заполняются модой 'S' |
