## Описание данных

Используется классический датасет **Titanic** (Kaggle). Содержит информацию о 891 пассажире.

| Столбец | Описание | Тип | Особенности |
| :--- | :--- | :--- | :--- |
| **PassengerId** | Уникальный идентификатор | int | Не влияет на выживание |
| **Survived** | Целевая переменная: 1 – выжил, 0 – погиб | int | 38% выживших |
| **Pclass** | Класс билета (1-й, 2-й, 3-й) | int | Социально-экономический статус |
| **Name** | Полное имя | str | Можно извлечь титул |
| **Sex** | male / female | str | Очень сильный признак |
| **Age** | Возраст в годах | float | 20% пропусков |
| **SibSp** | Кол-во братьев/сестёр или супругов на борту | int | Семейное положение |
| **Parch** | Кол-во родителей или детей на борту | int | Семейное положение |
| **Ticket** | Номер билета | str | Много уникальных, будет удалён |
| **Fare** | Стоимость билета (фунты) | float | Сильный перекос, есть выбросы |
| **Cabin** | Номер каюты | str | 77% пропусков, будет заменён флагом |
| **Embarked** | Порт посадки (C, Q, S) | str | 2 пропуска, заполнены модой |

## Ключевые выводы

### 1. Пол и класс — главные факторы выживания
- **Женщины** выживали в **74%** случаев, мужчины — только в **19%**.
- Пассажиры **1-го класса** выживали в **63%** случаев, 3-го класса — лишь **24%**.

### 2. Семейные признаки дублируют информацию
- Корреляция между `SibSp` и `Parch` составляет **0.41** — это говорит о том, что люди путешествовали семьями.
- **Решение:** объединить их в один признак `FamilySize = SibSp + Parch + 1` или бинарный `IsAlone`.

### 3. Возраст обратно связан с размером семьи
- Корреляция `Age` с `SibSp` = **-0.31**, с `Parch` = **-0.19**.
- Молодые пассажиры чаще путешествовали с родственниками.
- **Решение:** создать признак `Child` (возраст < 12 лет) — это усилит предсказательную способность.

### 4. Стоимость билета коррелирует с семьёй
- `Fare` положительно коррелирует с `SibSp` (0.16) и `Parch` (0.22).
- Более дорогие билеты часто покупали семьи.
- Этот факт будет учтён при построении модели — возможно, важность `Fare` снизится после добавления `FamilySize`.

## План предобработки (на основе EDA)

На следующем этапе (проект №2) данные будут подготовлены для обучения моделей:

| Признак | Действие |
| :--- | :--- |
| **Age** | Заполнить медианой (28 лет) |
| **Cabin** | Удалить, создать бинарный флаг `Has_Cabin` |
| **Embarked** | Заполнить модой ('S') |
| **SibSp, Parch** | Объединить в `FamilySize` |
| **Name, Ticket** | Удалить (неинформативны) |
| **Sex, Pclass, Embarked** | Закодировать (One‑Hot / Label) |
| **Fare** | Применить логарифмическое преобразование для борьбы с перекосом |
